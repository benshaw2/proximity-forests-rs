# Proximity Forests

A high-performance implementation of Proximity Forests and related forest-induced geometry methods, with a Rust core and Python bindings.

> **Status:** Early development. APIs, model formats, and behavior may change before the first stable release.

## Overview

Proximity Forests replace conventional attribute-threshold splits with proximity-based splits. At each internal classification node, candidate splitters are generated by selecting a distance configuration and one exemplar for each class represented at that node. Each observation follows the branch of its nearest exemplar, and the best candidate splitter is retained according to the configured split criterion.

This repository is intended to provide a reusable foundation for:

- proximity forest classification and regression;
- proximity-based isolation forests;
- vector, univariate time-series, and multivariate time-series inputs;
- elastic and non-elastic distance measures;
- deterministic parallel fitting and prediction;
- forest proximities and sparse leaf-incidence representations;
- ForestGeom-compatible forest geometry;
- proximity-based outlier detection;
- missing-data imputation;
- Python and Rust APIs backed by the same implementation.

## Project Goals

- Keep numerical kernels, tree construction, traversal, aggregation, and parallel execution in Rust.
- Expose a Python API shaped like familiar scikit-learn forest estimators without requiring scikit-learn at runtime.
- Preserve deterministic results across supported thread counts and execution schedules.
- Support model inspection through methods such as `apply(X)`.
- Align proximity-isolation scoring with the standard Isolation Forest path-length formulation while changing only the node-splitting mechanism.
- Support future PF-GAP-style proximities, imputation, outlier scoring, and ForestGeom integration.

## Current Python API

The initial Python package exposes:

```python
from proximity_forests import (
    ProximityForestClassifier,
    ProximityForestRegressor,
    ProximityIsolationForest,
)
```

Implemented estimator methods currently include:

- `fit(X, y)` for classification and regression;
- `fit(X)` for isolation;
- `predict(X)`;
- `predict_proba(X)` for classification;
- `apply(X)`;
- `score_samples(X)` for isolation;
- `decision_function(X)` for isolation;
- `get_params()` and `set_params()`.

The isolation implementation also retains the canonical anomaly score internally, where larger values indicate more anomalous observations. A direct public Python method for this raw score is planned.

## Current Rust Implementation

The Rust core currently includes:

- owned numeric and multivariate observation stores;
- classification and regression target containers;
- deterministic seed derivation and random-stream isolation;
- bootstrap-aware compact node membership;
- typed distance configurations;
- univariate, vector, independent multivariate, and dependent multivariate distance kernels;
- reusable distance scratch buffers;
- early abandoning where supported;
- class-aware exemplar sampling;
- candidate routing and scoring;
- iterative arena-backed tree construction;
- fitted leaf payloads for classification, regression, and isolation;
- iterative tree prediction;
- forest-level prediction aggregation;
- batch prediction and leaf assignment;
- tree-level parallel forest fitting;
- model-owned fitting observations for self-contained prediction.

## Development Setup

The Python bindings are built with PyO3 and maturin.

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install maturin numpy pytest ipykernel

maturin develop
pytest
```

To use the project from Jupyter without installing a second Jupyter application into the environment:

```bash
python -m ipykernel install \
    --user \
    --name proximity-forests-rs \
    --display-name "Proximity Forests (Rust)"
```

Then select **Proximity Forests (Rust)** as the notebook kernel.

## Example

```python
import numpy as np

from proximity_forests import ProximityForestClassifier

rng = np.random.default_rng(42)

X_left = rng.normal(loc=(-2.0, -2.0), scale=0.4, size=(100, 2))
X_right = rng.normal(loc=(2.0, 2.0), scale=0.4, size=(100, 2))

X = np.vstack([X_left, X_right])
y = np.array(["left"] * len(X_left) + ["right"] * len(X_right))

model = ProximityForestClassifier(
    n_estimators=50,
    n_candidates=5,
    max_depth=10,
    bootstrap=True,
    random_state=42,
    n_jobs=-1,
)

model.fit(X, y)

predictions = model.predict(X)
probabilities = model.predict_proba(X)
leaf_ids = model.apply(X)

print(predictions[:5])
print(probabilities[:5])
print(leaf_ids.shape)
```

`apply(X)` returns a sample-by-tree matrix of terminal node identifiers. This representation will support forest proximities, sparse leaf-incidence maps, and ForestGeom integration.
